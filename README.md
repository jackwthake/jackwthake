# Hi, I'm Jack

I build systems software close to the metal — from **3D renderers running on ARM microcontrollers** to **compilers targeting 50-year-old CPUs**. I like understanding how things work at the lowest level and building things that actually run on real hardware.

---

## Featured Projects

**[C02](https://github.com/jackwthake/C02)** - Compiler for a custom systems language targeting the 65C02
> Complete compiler pipeline in Rust — tokenizer, recursive descent parser, lexically scoped semantic analyzer, and code generator. Emits native 65C02 assembly with a zero-page virtual register ABI. Runs on real hardware.

**[shader-works](https://github.com/jackwthake/shader-works)** - Software 3D renderer with zero dependencies
> Complete CPU-based graphics pipeline in pure C. Renders 3000+ triangles at 40 FPS without a GPU. Ported to ARM Cortex-M4 microcontroller (200MHz, 192KB RAM) with a fully functional voxel world demo.

**[secure-serve](https://github.com/jackwthake/secure-serve)** - Multithreaded HTTPS server in C++
> Built from raw POSIX sockets with OpenSSL, dynamic thread pooling, and smart pointer memory management.

**[ai-survival](https://github.com/jackwthake/ai-survival)** - Multi-agent AI survival sandbox
> Browser-based experiment in emergent social behavior. Two AI agents develop their own survival strategies and social dynamics unprompted.
